## 概要

自身で構成・デザインを検討し、Webサイトのコーディングを行いました。
閲覧者にとって見やすく、使いやすいUIを意識して設計しました。

## URL 

* デモサイト：https://portfolio-amber-delta-22.vercel.app/

## 使用技術 

* HTML
* SCSS
* JavaScript
* microCMS
* Three.js/WebGL
* Blender(過去作品の3Dモデル部分)
  
* 開発環境：Vite
* デプロイ：Vercel

## 実装内容

### ① CMS連携（microCMS）

microCMSを利用し、記事の投稿・更新が可能な構成にしています。
APIを用いてデータを取得し、動的にコンテンツを表示しています。

### ② レスポンシブ対応

モバイルファーストで設計し、スマートフォン・タブレット・PCで見やすいレイアウトにしています。

### ③ インタラクション

JavaScriptを用いて、スクロールや操作に応じて画面が変化するインタラクションを実装しています。

### ④ 3D表現（Three.js）

Three.jsを用いて、ユーザーの操作に応じて形状が変化する3Dオブジェクトを実装しました。
Raycasterを用いてマウス位置を3D空間に変換し、その座標を配列として保持、Shaderにuniformとして渡すことでオブジェクトの変形に
反映させています。また、過去の座標を一定数保持することで、連続的な変形表現を実現しています。

## 工夫した点

* microCMSを導入し、更新・運用しやすい構成にした
* モバイルファーストで設計し、幅広いデバイスで見やすいUIにした
* 情報が伝わりやすいよう、シンプルなレイアウト構成を意識した
* Three.jsによる表現を取り入れつつ、コンテンツの可読性を損なわない設計にした

## 課題・改善点

* JavaScriptの処理をより整理し、可読性・保守性を向上させたい
* Three.jsのパフォーマンス最適化に改善の余地がある
